# 🧠 AI Mental Fitness Tracker

## 📌 Overview
The AI Mental Fitness Tracker is an intelligent system designed to analyze user behavior and self-reported inputs to assess mental well-being. Using machine learning techniques, the system identifies mental fitness patterns and provides personalized insights to support stress management and emotional awareness.

This project demonstrates the application of **AI in mental health analytics**, focusing on data-driven assessment rather than clinical diagnosis.

---

## 🎯 Objectives
- Analyze mental wellness indicators using structured data
- Build predictive models to classify mental fitness levels
- Generate meaningful insights from user behavioral patterns
- Apply machine learning responsibly in a sensitive domain

---

## 🧠 Machine Learning Approach
- **Problem Type:** Supervised Learning (Classification)
- **Algorithms Used:**
  - Logistic Regression
  - Support Vector Machine (SVM)
  - Random Forest Classifier
- **Evaluation Metrics:**
  - Accuracy
  - Precision
  - Recall
  - F1-Score
